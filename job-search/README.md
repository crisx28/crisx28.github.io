## How to use it in 15 minutes

1. Open `job-leads.md`, open the **📧 email** leads first, confirm each is still live.
2. Copy the matching email from `emails/`, fill the `[[brackets]]`, cut a sentence or two.
3. Run the **sending checklist** at the bottom of `emails/00-master-template.md` before sending.
4. For **🔘 platform-apply** leads, paste the same email into the board's "message to hiring
   manager" box.
5. Set the LinkedIn saved-search alert (instructions in `job-leads.md`) so new postings come
   to you daily instead of you re-searching.

## Honest limits of this kit

- I can't log into LinkedIn or scrape live postings — the boards block automated access — so
  **verify hours, pay, and open/closed status on the live link before applying.**
- No email was sent for you: the Gmail connector isn't enabled in this chat. These are
  ready-to-send drafts you review and send yourself (or enable Gmail and I can draft into it).
- No tool "beats" AI detectors reliably. These emails pass because the content is genuinely
  yours and specific to each reader — that's the only thing that holds up.
